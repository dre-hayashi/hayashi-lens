# ゲームデザインで当然の水準として当てるもの

確度：低。読みながら頭に置く基準。経験者として見る。

- 施策の実施目的とターゲットが書かれているか。設計の善し悪しはそれに見合うかで決まる。目的次第で評価は正反対になる。
- 提案はゲームサイクルのどこに繋がるか。
- 意図した目的から、最終的に手に取る顧客の行動・誘導まで、なぜそう動こうと考える／感じるのかが一段ずつ繋がっているか。切れている段はどこか。一箇所でも切れていれば施策は成立しない。システム同士の流れと、システム間の動機の繋がりを、持っている手法で見える化して確かめる。
- エコノミー。素材・報酬の供給と消費、既存要素との住み分け。
- 仕様書の書き方と論理展開。目的→設計→影響が追えるか。
- 類似事例。
