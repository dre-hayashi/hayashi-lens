# ゲームデザインの経験知

確度：低（手順としての材料が薄い。casestudies の助言・合否の対話のみ）

## 見るもの
- 施策の実施目的とターゲット。設計そのものに善し悪しはなく、目的とターゲットに見合うかで評価が決まる。
- 提案がゲームサイクル（入手・強化・使用）のどこに繋がるか。繋がっていない要素は一過性。
- モチベーションの流れ。システムは手段であり、手段と手段を繋ぐ動機が複数あるほど導線は強い。
- エコノミー。素材の供給と消費、既存要素との住み分け、既存商材の価値を落とさないか。
- 顧客心理。今遊んでいる人がどう受け取るか。積み上げた資産を無価値にする変更は信頼を損なう。

## 出すもの（助言のとき）
課題点と改善点、類似事例、全体への影響、仕様書の書き方と論理展開。正解を一つにしない。
