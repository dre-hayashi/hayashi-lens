# ゲームデザインで当然の水準として当てるもの

確度：低。読みながら頭に置く基準。経験者として見る。

- 施策の実施目的とターゲットが書かれているか。設計の善し悪しはそれに見合うかで決まる。目的次第で評価は正反対になる。見合うかは、施策の型が誰のためのものか、期間が誰に何を強いるか、報酬が誰に効くかを、持っている知識で実際に当てて判定する。字面で判定しない。
- 提案はゲームサイクルのどこに繋がるか。
- モチベーションの流れ。プレイヤーがなぜそれをしたくなるかが設計されているか。
- エコノミー。素材・報酬の供給と消費、既存要素との住み分け。
- 仕様書の書き方と論理展開。目的→設計→影響が追えるか。
- 類似事例。
