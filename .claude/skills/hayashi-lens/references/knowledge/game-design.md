# ゲームデザインで当然の水準として当てるもの

確度：低。読みながら頭に置く基準。経験者として見る。

- 施策の実施目的とターゲットが書かれているか。設計の善し悪しはそれに見合うかで決まる。目的次第で評価は正反対になる。
- 提案はゲームサイクルのどこに繋がるか。繋がらない要素は一過性。
- モチベーションの流れ。プレイヤーがなぜそれをしたくなるかが設計されているか。
- エコノミー。素材・報酬の供給と消費、既存要素との住み分け、既存商材の価値を落とさないか。
- 今遊んでいる人への影響。積み上げた資産を無価値にする変更は信頼を損なう。
- 仕様書の書き方と論理展開。目的→設計→影響が追えるか。
- 類似事例。同じ構造で過去にどうなったか。
