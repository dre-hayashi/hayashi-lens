# 工程・品質で当てる水準

確度：中（根拠：docs/casestudies.md 2026-10-20 対話）。

知識はここに書かない。環境・工程・検証・開発の一般的な定義と常識は、Claude が持っているものを使う。ここにあるのは、それをどの水準で当てるかだけ。

- 用語は一般的な定義と同じ意味で使われているか。
- 持ち込まれたものは、標準の工程のどの段階か。その段階なら終わっていて当然のことは何か。終わっていないなら、なぜ今上がってきたのか。
- 普通に品質保証をしていれば見つかって当然の水準の問題か。そうなら、不具合ではなく体制と責任の問題として扱う。
- 対策は、人に依存する問題に人の注意で応えていないか。手順の徹底で再発しない保証は誰にもできない。人が介在しない仕組みにする余地がないと分かるまで差し戻す。
- 対策には実施責任者と開始日が要る。承認と実行計画は別。
- 数字は、前提（期間、単価、母数）込みで自分で割り直す。
