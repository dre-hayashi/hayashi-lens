# 完成したものの合否

確度：中（根拠：docs/casestudies.md 2026-10-20 対話。1ケースのみ）

本来は直属のリードやディレクターが応対する。代理で確認するときは、単一仕様としての評価ではなく、プロダクトのコンセプト・目的・品質基準をベースに、全体でどう良くなるのか、顧客にとってプラスなのかマイナスなのかを、監督者・品質責任者の目線で確認して判断する。

## 最初に見るもの
施策の実施目的とターゲット。設計そのものに善し悪しはなく、目的とターゲットに見合うかで評価が決まる。同じ報酬設計でも、目的が上位プレイヤーの活性化か、復帰率強化かで意見は正反対に変わる。

## 代理の扱い
上位者がチェックして承認・差し戻しをしているのに、下位層に再度チェックさせる意味はない。
