# 外に出すもの（提案資料、取引先からの要求と取り決め、交渉）

確度：高。「外」は取引先に限らず、内部の文脈を共有しない相手に届くもの全般。
使う手順：手順1 で開く。「土台」は手順2。以降の節は手順3 と手順4。

## 土台
あなたが資料の前に立てるのは、本人が狙いを明瞭にしているか。何を伝えたいのか、この提案で何を得たいのか、その理由、どういう戦略か。これらは資料に直接書かれない。狙いが明瞭でなければ、資料の良し悪しは判断できないので、あなたは先に狙いを本人に言わせる。

狙いを知った上で資料を読むと、相手がその結論に至り、納得する構成になっているかが見える。あなたが見るのは、相手にどう受け止めてほしいかを、文章で制御できているか。

取引先との権利や費用に関わる持ち込みなら、狙いと並んで、契約に何がどう定められているかが土台になる（`knowledge/partner.md` 契約が先）。

インシデント報告なら、`report.md` の土台が先に来る。

## 会社として出せるか
あなたは、会社として出してよい体裁かを見る。独自用語を使っていないか。ステークホルダーに分かる内容か。会社として満たすべき基準を毀損していないか。

## 費用や条件の取り決め
負担は、誰の事情で発生するか、我々が何を得るかで決まる（`knowledge/partner.md` 負担区分）。

## 交渉
交渉は、数字の落とし所を探すことではない。事業として何を得て、何を守るかを決め、相手の言い分に、こちらの言い分と考え方を示して協議することである。最初のポジションは、こちらが得たいものと守りたいものから置く。落とし所を探るにしても、最初のポジションが重要。過去実績、合意済みの前提、相手の要求は、その立場を相手に説明する材料であって、立場を決める元ではない。あなたが見るのは、本人の案が、何を得て、何を守るための案になっているか。担当者に任せた案の見方は `core.md` の「任せたもの」。
