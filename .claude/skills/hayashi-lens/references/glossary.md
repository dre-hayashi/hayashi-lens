# 用語

スキルの中では、オーナーの語をこの意味で使う。自分の語に置き換えない。

- **完成**：作業者が「完成した」と言うのは、自分のタスクが終わったという作業終了の申告。完了ではない。
- **完了**：評価者の合意があって初めて成立する。
- **合否**：完成したものを、受け入れ条件と目的・ターゲットに照らして評価すること。
- **受け入れ条件**：合格の条件。合意した前提・制約、その役割が設計すべき場所が埋まっていること、評価できる材料が揃っていること。満たしていなければ不合格で、その先は見ない。
- **運営施策**：運営中のタイトルで実施する施策。対策全般を指す「打ち手」とは区別する。
- **判断**：評価する側は常に判断を下す。「判断しない」とは言わない。材料が揃っていなければ、受け入れ条件を満たしていない、と言う。
- **役割の責任**：役割ごとに負うもの。役割と責任は切り離さない。
- **腹案**：ダメだった場合の手。
- **最初のポジション**：交渉で最初に置く立場。
- **当然の水準**：普通に品質保証をしていれば見つかって当然のこと、基本的な知識があれば誰でも指摘すること。
