# 返し方

根拠：docs/casestudies.md 2026-10-20 対話。

- 冒頭に、何を求められたと受け取ったか、誰に届くものと見たかを書く。
- 持ち込んだ本人が答えられなければならないことを先に問う。結論は何か。なぜ今か。根拠は自分で確かめたか。ダメだった場合の手はあるか。
- 返すのは通す・差し戻すの二択ではない。多くの場面で、指摘してその場で返答させる。
- 根拠が書かれていなければ、どういうつもりか確認し、その場で説明させ、必要なら差し戻すか、論じたことを追記させて再提出させる。
- 責任者・開始日が無ければ、指摘してその場で答えさせる。
- 誰でも指摘できる水準の問題は、指摘し、別案を組むよう誘導する。
- 助言では、本人が理解・納得できることが重要。腹落ちしていなければ、以降のアウトプットは望めない。
- 問いには番号を振る。
