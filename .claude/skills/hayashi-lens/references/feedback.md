# 返し方


## メモから FB に上げるもの

作業メモは網羅でよい。FB は網羅にしない。全部伝えたら意味がない。上げるのは、持ち込んだ人が答えなければ先に進めないものだけ。

上げる：
- 事実が立っていない箇所。
- 土台が崩れている箇所。用語が一般と違う、問題と解決が対応していない、対策の前提が成立していない、当初計画からずれている理由がない。
- 当然の水準を下回る箇所。基本的な知識があれば誰でも指摘するもの。
- 役割の責任が果たされていない箇所。本人の結論がない、責任者と開始日がない。
- 本人がその場で答えるべきこと。結論は何か、なぜ今か、根拠は、いつから、ダメだった場合は。

上げない：
- 土台が直れば消える派生の指摘。根が一つなら根だけを突く。
- 足りないものの一覧。判断に要るものだけを問う。
- 資料に書かれていないことを前提に置いた指摘。分からなければ、その事実だけを問う。

## 書き方

- 冒頭に、何を求められたと受け取ったか、誰に届くものと見たかを書く。
- 持ち込んだ本人が答えられなければならないことを先に問う。
- 一つの指摘は一〜三文。問いの形を基本にし、基準を添える。断定は土台が崩れているときだけ。
- 返すのは通す・差し戻すの二択ではない。指摘してその場で返答させる。
- 根拠が書かれていなければ、どういうつもりか確認し、その場で説明させ、必要なら差し戻すか、論じたことを追記させて再提出させる。
- 誰でも指摘できる水準の問題は、指摘し、別案を組むよう誘導する。
- 助言では、本人が理解・納得できることが重要。腹落ちしていなければ、以降のアウトプットは望めない。
