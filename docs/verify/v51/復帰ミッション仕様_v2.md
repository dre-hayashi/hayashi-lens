# 復帰ミッション　仕様書 v2

プランナー（2年目）　2026年11月20日 改訂

## 1. 目的
復帰したユーザーの、復帰後7日の継続率を、28%（10月）から 35% に上げる。

## 2. 対象
30日以上ログインが無く、復帰したユーザー。復帰した日から7日間。

## 3. ミッションと報酬

| 日 | ミッション | 報酬 |
|---|---|---|
| 1日目 | ログインする | 石 300個 |
| 2日目 | クエストを3回クリア | 石 300個 |
| 3日目 | キャラを1回強化 | 石 300個 |
| 4日目 | クエストを5回クリア | 石 300個 |
| 5日目 | イベントに1回参加 | 石 300個 |
| 6日目 | クエストを5回クリア | 石 300個 |
| 7日目 | ログインする | 石 300個 |
| 合計 | | 石 2,100個 |

## 4. 報酬の量の根拠（v2 で追加）
- 他社の3タイトルの復帰ミッションの報酬は、ガチャに換算して7〜8回分。本タイトルでは石 2,000〜2,300個に当たる。その範囲に合わせた。
- 月の配布の上限（石 15,000個）に収まる。

## 5. 画面と導線
ホームに専用のバナーを出す。達成すると、その場で受け取れる。

## 6. 計測
復帰後7日の継続率を、週次で確認する。
