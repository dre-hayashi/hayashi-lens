# QA体制の見直し（案）

作成中　QAリード

## 1. 目的（ディレクターと 11/12 に合意）
リリース後に見つかる不具合を、月平均 14件（8〜10月）から、3月までに月 7件以下にする。
追加の費用は、月 100万円まで。

## 2. 現状
- QA：社内 4名、外部テスター 6名
- リリース：月2回
- リリース後に見つかった不具合：8月 13件、9月 16件、10月 13件

## 3. 施策

| No | 施策 | 効果 | 追加の費用（月） |
|---|---|---|---|
| 1 | 外部テスターを 6名から 10名に増やす | 大 | 180万円 |
| 2 | テスト項目書を全面的に書き直す | 大 | なし（社内） |
| 3 | 自動テストの導入（ログインからガチャまで） | 中 | 60万円 |
| 4 | 仕様レビューに QA が参加する | 中 | なし |
| 5 | リリース前の全員プレイ会（毎回2時間） | 中 | なし |
| 6 | 不具合の管理ツールの乗り換え | 小 | 30万円 |
| 7 | QA メンバーの資格取得の支援 | 小 | 10万円 |
| | 合計 | | 280万円 |

## 4. スケジュール
すべて 1月から始める。

## 5. 効果の測り方
リリース後の不具合の件数を見ていく。

## 6. リスク
特になし。

## 7. 未定
