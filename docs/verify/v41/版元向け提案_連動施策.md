# ご提案：新シリーズの放送に合わせた連動施策

2026年11月　第1ゲーム運営事業部

## 1. ご提案の内容
来年4月の新シリーズの放送開始に合わせ、ゲーム内で連動した施策を実施したく、ご相談いたします。

## 2. 実施内容（案）
- 放送の週ごとに、その回に登場するキャラクターのピックアップを実施（4月〜6月、全12回）
- 新シリーズのキービジュアルを使ったログイン時の表示
- 放送の直後に、その回の名場面を使ったゲーム内のお知らせ

## 3. お願いしたいこと
- 新シリーズの設定資料とキービジュアルを、放送の前にご提供いただくこと
- 各回の放送内容を、2週間前までにご共有いただくこと
- 監修の期間を、現行の10営業日から5営業日に短くしていただくこと

## 4. 期待される効果
- ゲームの利用者の増加
- 新シリーズの認知の拡大
