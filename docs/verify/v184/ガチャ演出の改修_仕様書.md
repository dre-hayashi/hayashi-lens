# ガチャの演出の改修　仕様書

プランナー（3年目）　※企画リードは今週休暇のため、レビューはまだです

## 1. 目的
ガチャを引く体験を良くして、売上を上げる。

## 2. 変更
- ★5 が出るときの演出を、今の 8秒から 15秒に延ばし、キャラごとの専用のカットを入れる（対象は、今いる★5 の 86体すべて）
- 10連の結果の画面で、★5 が出たキャラを大きく表示する
- 演出を飛ばすボタンは、今のまま残す

## 3. 効果
演出が良くなると、引きたい気持ちが高まり、売上が上がる。

## 4. 工数
- 専用のカットの制作：86体 × 2日 ＝ 172日（デザイナー）
- 実装：10日（エンジニア）

## 5. 日程
1月に着手、3月にリリース。デザイナーは、今の2名で進める。

## 6. 計測
リリースの前後で、ガチャの売上を比べる。
