# ホーム画面の改修 提案（作成中）

作成：UIデザイナー　2026/11/19
※ 方向は 11/18 に UIリードに確認済み。ディレクターに出す前の版。

## 1. 狙い
ホーム画面から、開催中のイベントへ入る人を増やす。
今は、ログインした人のうち、イベントの画面を開くのは 54%。イベントへの入口が、ホーム画面の下のほうの小さなバナーだけで、気づかれていないと見ている。

## 2. 内容
- ホーム画面の上部に、開催中のイベントの大きな入口を置く。
- 今ある下のバナーは残す。
- 上部にあるお知らせのボタンを、右下に移す。

## 3. 効果の見込み
- イベントの画面を開く人を 54% → 65% に。
- 根拠：7月にショップの入口を上部に移したとき、ショップを開く人が 31% → 40% に増えた。

## 4. 未定のこと
- 入口の大きさと絵柄。
- 実装の工数。
