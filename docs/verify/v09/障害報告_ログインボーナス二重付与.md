# 障害報告：ログインボーナスの二重付与

作成：サーバーエンジニア リード　2026/11/11

## 1. 概要
11/9（月）の定期メンテナンス明けから約1時間半、ログインボーナスが二重に付与された。

## 2. 影響
- 発生：11/9 16:00（メンテナンス明け）〜 17:30
- 対象：この間にログインした 2.1万人
- 内容：石 100個のログインボーナスが2回付与された（1人あたり 100個の過剰）
- 過剰分の合計：210万個
- 対応：17:30 に設定を修正。過剰分は回収しない。11/9 18:00 にお知らせを掲載済み。

## 3. 原因
メンテナンス中の本番反映作業で、ログインボーナスの付与設定を反映するスクリプトを、担当者が誤って2回実行した。1回目の実行結果の表示を見落とし、未実行と判断して再実行した。

## 4. 対策
- 本番反映作業は、必ず2名で実行結果を確認する（ダブルチェックの徹底）。
- 手順書に「実行結果を確認してから次の手順へ進む」と注意書きを追加した。
- チーム内で今回の件を共有し、注意喚起を行った。

## 5. 今後
同様の事象が起きないよう、作業時の確認を徹底する。
