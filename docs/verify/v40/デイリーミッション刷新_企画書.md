# 新機能「デイリーミッション刷新」企画書（作成中）

作成：プランナー　2026/11/19
※ 方向は 11/18 に企画リードに確認済み。ディレクターに出す前の版。

## 1. 狙い
毎日遊ぶ人を増やす。DAU は半年前の 13.5万人から 11.8万人に下がっている。デイリーミッションが半年間変わっておらず、飽きられていると見ている。

## 2. 内容
- デイリーミッションを、毎日5個の固定から、毎日ランダムに3個に変える。
- 3個すべて達成すると、石 30個（今は、5個達成で石 50個）。
- 週に5日達成すると、追加で育成素材。

## 3. 効果の見込み
- DAU を 11.8万人 → 12.5万人に。
- 根拠：他社のタイトルで、デイリーミッションを刷新して DAU が伸びた事例がある。

## 4. 未定のこと
- ミッションの中身の種類。
- 実装の工数。
