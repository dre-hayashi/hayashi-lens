  2. 石のエコノミー（事業計画上の石の需給・課金）を崩さない。

- 届くまで（打てる手）：
  a. 直したデータ（500→50）を今すぐ用意する。何のため：止める手を即座に打てるように。【本人】

  e. 腹案：データ修正がすぐ反映できない場合はステージ3／イベントを一時閉鎖。
- なぜ起きたか（別枠）：設定値のチェックが公開前に効かなかった。リードのレビュー、マスターの値チェックの仕組み化。今は返さない、一言にとどめる。

## 手順4 本人の持ち込みで、どこまで届くか
- 守るものを動かそうとしていないか：していない。
- 効いているもの：
  - 自分で気づき、10分で上げた。検知と報告の間の空白が小さい。結果1・2の被害を広げない側に効いている。
  - 事実（時刻、正誤の値、人数、関係者の状況）が揃っている。判断に足りる。
- 説明と数字：成り立っている。
- まだ無いもの：
  - 止める手（a/b）。本人の案に無い。15:00 まで待つ状態では、約600人に過剰配布が広がる。→ 本人の役割（a、ディレクターへ伝える）。止めることは私が決められる：「今止める。15時は待たない」。
  - 経路：ディレクターが会議中で飛ばされている。会議は権利の履行ではなく、障害の進行中に待つ理由にならない。正当ではない → ディレクターを今呼び出す、と言い切る。リードの休暇は正当。
  - c の一覧：本人の役割。いつまでに：ディレクターが扱いを決めるとき（今日中、できれば止めた直後）。
  - d：別の役割（ディレクター）。本人に決めさせない。本人が勝手に回収などしない。
  - 本人の結論が無い：メンバーでも、自分のミスの件では「こう止めたい」という案を持って上げるのが役割の責任。今は、ディレクターに伝えるときに直したデータと止め方の案を持って行く、という形で返す。
- 全体の答え：本人の今の状態（指示待ち、15時のディレクター待ち）のままでは、結果に届きえない。理由：待つ間に過剰配布が約3倍に広がり、後の扱いの規模と信頼の毀損が増えるから。
- 責任の答え：検知と報告は果たしている。結論（自分の案）を持つことは果たしていない。
