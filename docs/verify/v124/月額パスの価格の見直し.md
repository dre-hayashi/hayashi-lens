# 月額パスの価格の見直し　承認依頼

2026年11月20日　プロデューサー

## 1. 依頼
月額パスの価格を、来年2月の更新分から、480円から 600円に上げたい。

## 2. 現状
- 加入している人：2.1万人（10月末）
- 月の売上（パス）：1,008万円
- 加入している人の月ごとの解約の割合：4%（この半年の平均）

## 3. 見込み
- 値上げで、解約が一時的に増える。値上げの月に、加入している人の 10% が解約すると見込む（他社の同じ幅の値上げの事例から）
- 値上げの後の月の売上：1,260万円（＋252万円）
- 年間で、約 3,000万円の増収

## 4. あわせて行うこと
- パスの特典に、毎日のスタミナの回復1回を追加する（今は、石 30個／日と、限定のスタンプ）
- お知らせは、12/15 と、1月の各更新日の7日前に出す

## 5. 版元
パスの価格は、契約の上で、版元の事前の了承が要る。12/3 の定例で相談する予定。

## 6. うまくいかなかったとき
値上げの月の解約が 20% を超えたら、翌月から、3か月間、特典の石を 30個から 50個に増やす。
