# 新イベント「ギルド対抗戦」企画書（作成中）

作成：プランナー　2026/11/18
※ 方向は 11/17 にリードに確認済み。ディレクターに出す前の版。

## 1. 狙い
ギルドに入っている人の、週あたりのログイン日数を増やす。
ギルドに入っている人の週のログイン日数は平均 4.2日で、入っていない人（3.1日）より多い。ただ、ギルドに入ってから3か月を過ぎると 3.6日まで下がる。ギルドでやることが、毎日の寄付と、週1回のギルドボスしか無いためと見ている。

## 2. 内容
- 週末（金〜日）に、ギルド同士が4組で競う。
- 各メンバーが専用ステージに1日3回まで挑戦でき、スコアの合計でギルドの順位が決まる。
- 順位に応じて、ギルドの全員に報酬（育成素材と、限定の称号）。
- 参加しなかったメンバーにも、ギルドの順位に応じた報酬の半分を配る。

## 3. 効果の見込み
- ギルドに入っている人の、週のログイン日数を 4.2日 → 4.6日に。
- 根拠：週1回のギルドボスを入れたとき（1月）に、3.8日 → 4.2日に上がった。

## 4. 未定のこと
- 報酬の量。
- 組み合わせの決め方（強さの近いギルド同士を当てるか）。
- 開発の工数（エンジニアにはまだ相談していない）。
