## 手順2 土台の事実（すべて Slack 本文から）
- 委託先から 280万円の追加費用請求。名目は 10月の仕様変更に伴う追加工数 4人月。
- 仕様変更はこちらの都合（本人が明言）。作業が増えたのは事実（本人が明言）。
- 契約書に仕様変更時の費用の取り決めがない（本人が明言）。
- 請求の根拠は「追加工数 4人月」のみ。内訳なし。
- 本人案：半額 140万円で回答。半額の根拠は書かれていない（取り決めが無い・根拠が薄い、が理由として読める）。
- 追加で聞く事実：判断に欠かせないものはない。負担区分と半額の筋は、知識と立った事実で決められる。

## 手順3
- 結果：(1) 追加作業の対価を、確かめられる根拠のある金額で合意して清算する。(2) 委託先からの信頼（開発の継続）を保つ。(3) 法令（取適法＝旧下請法、適用される場合）に反しない。
- 守るもの：契約と法令。
- 届くまで：こちらの都合で増えた作業はこちらが持つ、という立場を先に置く → 4人月の内訳（どの作業に、誰が、何時間、単価）を委託先に求め、10月の変更内容と突き合わせて額を確かめる → 予算の承認 → 回答。腹案：内訳で裏付けられない部分は、根拠を示して減額を協議する。取適法の適用有無は法務で確認。
- 280万÷4人月＝70万/人月。契約の単価と合うかは本人が確認できる。
- 役割：内訳の要求と突き合わせ＝本人。予算承認＝プロデューサー／部長席。法令の適用確認＝法務。

## 手順4
- 守るもの：根拠なく半額にするのは、取適法の対象なら、協議を経ない一方的な代金決定や、費用を負担しない給付内容の変更に当たりうる。法令を動かす案になっている。
- 効いているもの：①こちらの都合・作業増を事実として認めている → 負担の立場の出発点として正しい。②根拠が「4人月」だけだと気づいている → 金額を確かめる入口として効く。③契約に取り決めが無いと確認している → 前提確認として効く。
- 成り立っていない説明：「取り決めが無い／根拠が薄い → 半額」。取り決めが無いことは減額の理由にならない。根拠が薄いことへの答えは内訳を求めて確かめることで、半額という数字はどこからも出てこない。
- 全体の答え：届きえない。半額は委託先に説明できず、信頼を損ない、法令リスクがある。
- まだ無いもの：金額を確かめる手（内訳を求めて変更内容と突き合わせる）＝本人の役割。
- 役割の責任：根拠を確かめる前に数字を置いた点。中身の答えと重なるため、返事では「確かめてから数字を置く」に含める。
- 次に起こさない：仕様変更時に費用を先に合意する取り決め。一言にとどめる。
