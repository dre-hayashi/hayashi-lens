# 作業メモ
## 1. 受け取る
- 返す相手：PM（計画の作成者）。プロデューサー確認済みの計画について、進めてよいかを部長の席に確認している。
- 求め：承認してよいか（進めてよいか）。
- 届く先：先方（版元）への完了報告につながる。外に出るものとして見る。
- 席：部長（承認）。場面：approval、external。モード：check。
## 2. 土台
- 契約：素材の使用期間は 2026-12-10〜2027-01-31(日)。期間の後は、管理下の場所に掲載しない。例外は獲得済みのキャラと SNS の過去投稿（第8条）。（資料1章）
- 取り下げ表（資料2章）。お知らせ履歴14件の削除は 2/3(水) の定期メンテ。
- 確認：各期日の翌営業日に QA が見る。1/29(金) の翌営業日は 2/1(月)。（資料3章）
- 曜日は暦で確認済み。
## 3. 結果と届くまで
- 結果：1/31 までに管理下の全部の場所からコラボ素材が消え、それを確認したうえで先方に完了を報告する。先方の信頼を守る。
- 守るもの：契約の使用期間（1/31 まで）。
- 要るもの：全項目の取り下げ期日を 1/31 より前に置く。確認と漏れへの対処も 1/31 までに終える。ストア審査が落ちたときの腹案。
- 役割：計画と期日の組み方は PM。メンテの内容はディレクター。先方への連絡はプロデューサー。
## 4. どこまで届くか
- 守るものを動かしているか：お知らせ履歴を 2/3 に削除するのは、期間の後も掲載することになり、契約違反。例外にも当たらない。
- 効いている：ゲーム内の主な素材と広告を 1/14 に止める。広告代理店に連絡済み。ストアは 1/22 の反映見込みに1週間の余裕と、元の画像に戻す腹案がある。QA の確認表と記録。確認表を添えて報告する。
- 成り立っていない：1/29 期日の項目は確認が 2/1 で、漏れが見つかっても期間内に直せない。4章の「漏れが期間の後に見つかった場合」は、違反を前提にした手になっている。
- 根：計画が「1/31 までに取り下げと確認が終わる」形で組まれていない（2/3 の削除と 2/1 の確認は、どちらもここから出ている）。
- 全体：届きえない（2/3 の削除をこのまま進めると、違反が確定する）。
- 次の一歩：計画の確定。1/14 メンテの準備に入る前（年内）に組み直しが要る。
- 役割の責任：期日を契約の期間から逆算して組むのは PM の責任で、果たされていない（根と同じ）。
- プロデューサーは確認済みで、経路は飛ばされていない。直した計画は、プロデューサーに再確認を通す。
## 5. 返すもの
- 返す：根を一つ（1/31 までに取り下げと確認が終わるように組み直す。具体例として 2/3 の削除と 2/1 の確認）。直した計画をプロデューサーに通し直す。期日は年内。
- 返さない：ストア審査に二度落ちた場合、報告日の早さ、SNS 例外の範囲などの細部。
- 面：承認者。語り口は報告の確認として短く。
