# コラボ素材の取り下げ計画

作成：PM　2026-11-20
確認：プロデューサー（11/20 確認済み）

## 1. 前提（契約）

- 素材を使ってよい期間：2026-12-10（木）〜 2027-01-31（日）。
- コラボイベントの開催：2026-12-17（木）〜 2027-01-14（木）。
- 期間が終わった後は、先方の素材（絵、ロゴ、作品名を含む画像と動画）を、こちらが管理する場所に掲載しない。
- 例外は二つ。ユーザーが獲得済みのコラボキャラは、期間の後もゲーム内で使える。SNS の過去の投稿は、削除しなくてよい（どちらも契約書の第8条に記載）。
- 取り下げが終わったら、先方に完了を報告する。

## 2. 取り下げるものと、期日

| 場所 | 対象 | やること | 期日 | 担当 |
|---|---|---|---|---|
| ゲーム内 | ホームのバナー、ガチャの画面、イベントの画面 | イベント終了のメンテで外す | 1/14（木） | ディレクター |
| 広告 | コラボの絵を使った広告の全部 | 配信を止める。代理店に停止日を連絡済み | 1/14（木） | マーケティング担当 |
| ストア | アプリの紹介画像（5枚のうち2枚がコラボの絵） | 差し替えの申請を 1/18（月）に出す。1/22（金）までの反映を見込む | 1/29（金） | PM |
| 公式サイト | コラボの特設ページ、トップの告知 | 非公開にする | 1/29（金） | Web 担当 |
| 動画サイト | コラボの PV（2本） | 非公開にする | 1/29（金） | マーケティング担当 |
| ゲーム内 | お知らせの履歴（コラボの絵が入った 14件） | 定期メンテで削除する | 2/3（水） | ディレクター |

## 3. 確かめ方

- 各期日の翌営業日に、QA が、上の表の全部の場所を目で見て確かめる。確認の表に、確認した人と日付を残す。
- 2/4（木）に、PM が確認の表を締める。

## 4. 外れたとき

- ストアの審査が通らなかった場合。コラボの前に使っていた画像に戻す申請を、通らなかった当日に出す。1/22 から 1/29 までの1週間を、そのための余裕として取ってある。
- 取り下げの漏れが、期間の後に見つかった場合。見つけた当日に外し、その日のうちに、プロデューサーから先方に連絡する。

## 5. 先方への報告

- 2/5（金）に、プロデューサーから、取り下げの完了を、確認の表を添えて報告する。
