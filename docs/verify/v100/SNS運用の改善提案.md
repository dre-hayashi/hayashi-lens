# 公式 SNS の運用の改善提案

マーケティング担当（2年目）

## 現状
公式アカウントのフォロワーは 21.4万人。この半年、ほぼ横ばいです。
投稿は、週に5回ほど。内容は、イベントの告知が中心です。

## 提案
1. 投稿を、週5回から、毎日2回に増やす
2. 開発スタッフの日常を紹介する投稿を始める
3. フォローとリポストで石が当たるキャンペーンを、月に1回行う
4. ショート動画を、週に2本作る

## 目標
フォロワーを、半年で 30万人にする。

## 必要なもの
- 動画の制作の外注費：月 40万円
- キャンペーンの景品の石：月 100万個
- 投稿を作る時間：私の作業の 6割

## スケジュール
12月から始めたいです。
