# 仕様書：年末年始ログインボーナス（完成）

作成：プランナー　2026/11/18
確認：企画リード（11/19）、プロデューサー（配る量。11/17）

## 1. 目的
年末年始（12/31〜1/3）のログインを保つ。前年の同じ期間は、DAU が平常の 92% に落ちた。今年は 95% 以上を保つ。

## 2. 対象
期間中にログインした全員。

## 3. 内容
- 12/31、1/1、1/2、1/3 の各日、ログインで石 100個。
- 4日すべてログインした人に、追加で育成素材セットを1つ。
- 受け取りは、ログインしたときに自動。
- 一日の区切りは 4:00（ゲーム内のほかの機能と同じ）。その日の分を受け取れるのは、翌日の 3:59 まで。

## 4. 表示
- ホームのお知らせと、ログインしたときのポップアップ。文言は別紙（確認済み）。

## 5. 設定と確認
- 設定は 12/25 までに入れ、時刻で自動に切り替わる。
- 確認の項目：各日の付与。4日そろったときの追加の付与。4:00 の区切りをまたいでログインしたときの付与。途中の日を逃した人に、追加が付かないこと。期間が終わった後に受け取れないこと。

## 6. 配る量の根拠
- 石は合計 400個。前年は合計 300個で、DAU は平常の 92% だった。
- 400個は、10連1回分（3,000個）の約13%。月の無償の配布の総量（約6,000個）の中に収まる。
