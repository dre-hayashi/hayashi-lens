# イベント報酬の配布の誤りについて（報告）

2026年11月20日　ディレクター

## 1. 起きたこと
11/17（火）15:00 に配った「秋のイベントの達成の報酬」で、対象ではないユーザー 3,214人にも、石 500個を配った。
11/17 16:20 に、CS への問い合わせで分かった。17:05 に、プロデューサーと部長に第一報を入れた。

## 2. 原因
配布の対象を抜き出す条件の式に、誤りがあった（「イベントを達成した人」とすべき所が、「イベントに参加した人」になっていた）。
式は、担当のプランナーが書き、別のプランナーが目で確認していた。

## 3. 対応（済み）
- 誤って配った石は、回収しない（プロデューサーと 11/17 に決定。版元には 11/18 に報告し、了承済み）
- 正しい対象の人には、予定どおり配れている
- お知らせを 11/18 に出した

## 4. 再発防止
- 配布の対象を抜き出す式を、人が書くのをやめる。配布の種類ごとの定型（達成、参加、順位）を、管理ツールの中に用意し、選ぶだけにする
- 配布の実行の前に、対象の人数を、イベントの集計の人数と自動で突き合わせ、5% 以上ずれていたら実行できないようにする
- 責任者：エンジニアリード。11/25 に着手、12/9 のメンテで入れる
- それまでの3週間に予定している配布は2件（11/26、12/2）。この2件は、ディレクターが、実行の前に、対象の人数と集計の人数を自分で突き合わせる

## 5. 影響
誤って配った石は、合計 160.7万個。経済設計の担当と確認し、12月の配布の上限の中で吸収する（12月のログインボーナスを、1日だけ減らす）。
