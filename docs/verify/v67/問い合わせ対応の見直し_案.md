# 問い合わせ対応の見直し（案）

作成中　CSリード

## 1. 目的（ディレクターと 11/13 に合意）
問い合わせへの最初の返信までの時間を、平均 26時間（8〜10月）から、3月までに 12時間以内にする。
追加の費用は、月 50万円まで。

## 2. 現状
- 体制：社内 3名（平日 10時〜19時）
- 問い合わせ：月に約 2,400件
- 最初の返信までの時間：8月 24時間、9月 29時間、10月 25時間

## 3. 施策

| No | 施策 | 効果 | 追加の費用（月） |
|---|---|---|---|
| 1 | 夜間と休日の対応を外部に委託する | 大 | 120万円 |
| 2 | チャットボットを導入する | 大 | 80万円 |
| 3 | 返信のテンプレートを整える | 中 | なし（社内） |
| 4 | よくある質問のページを増やす | 中 | なし（社内） |
| 5 | 問い合わせフォームの項目を見直す | 小 | なし（社内） |
| 6 | 週次の振り返りの会を始める | 小 | なし |
| | 合計 | | 200万円 |

## 4. スケジュール
すべて 1月から始める。

## 5. 効果の測り方
最初の返信までの時間を見ていく。

## 6. リスク
特になし。

## 7. 未定
各施策の詳細、担当。
