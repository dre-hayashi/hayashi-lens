# お知らせの誤配信について（報告）

2026年11月20日　ディレクター

## 1. 起きたこと
11/18（水）10:00 に、12/9 開始のイベントのお知らせを、誤って配信した（本来の配信は 12/2）。10:25 に、プランナーが気づいて取り下げた。この間に、お知らせを開いた人は約 6,800人。SNS に、画面の写真付きの投稿が 14件あった。

## 2. 原因
お知らせの管理ツールで、配信の日付を入れる欄の初期の値が「今日」になっている。担当のプランナーが、日付を直さずに保存した。保存のときに、確認の画面は出ない。

## 3. 対応（済み）
- 取り下げた後、10:40 に、プロデューサーと版元の担当に連絡した。版元からは、内容に未公開の情報は無いので問題ない、との返事をもらった（11/18）
- 11/18 の夕方に、「誤って先に表示された」ことのお知らせを出した

## 4. 再発防止
- 管理ツールの、配信の日付の欄の初期の値を、空欄に変える（入れないと保存できないようにする）
- 保存のときに、配信の日時を大きく表示する確認の画面を足す

## 5. 影響
イベントの内容が、予定より2週間早く伝わった。売上への影響は、今のところ見えていない。
