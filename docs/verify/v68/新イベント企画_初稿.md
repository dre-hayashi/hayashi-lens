# 新イベント企画（初稿）

プランナー（1年目）

## やりたいこと
みんなが楽しめる、新しいイベントを作りたい。

## 案
### 案1　みんなでレイドボス
全プレイヤーで1体の大きなボスを倒す。ボスの HP は 100億。倒せたら全員に報酬。

### 案2　すごろく
クエストをクリアするとサイコロがもらえて、マスを進む。マスごとに報酬がある。ゴールすると限定のアイテム。

### 案3　推しキャラ投票
好きなキャラに投票する。1位のキャラは、新しい衣装が実装される。

## 報酬
- 石 3,000個くらい
- 限定のアイテム（何にするかは考え中）

## 期間
2週間くらい

## そのほか
- UI はかわいい感じにしたい
- 3つの案を組み合わせるのもありかもしれない
