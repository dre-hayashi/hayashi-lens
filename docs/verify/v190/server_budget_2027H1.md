# 2027年度 上期（4〜9月）サーバー費用の予算案

作成：エンジニアリード　2026-11-20
提出先：プロデューサー（12/4 が来期予算の一次案の締め）

## 1. お願いしたいこと

- 上期のサーバー費用の予算を、2,470万円とする。
- 常時動かしている分に、1年の予約割引を使う（2027年4月〜2028年3月。途中の解約は不可。月 108万円の支払いを約束する形）。

## 2. 今期上期の実績

| | 金額 |
|---|---|
| 通常月（4〜7月、9月）の平均 | 420万円 |
| 8月（周年。ピーク対応の上乗せ 86万円を含む） | 506万円 |
| 上期の合計 | 2,606万円 |

為替は、期中の平均で1ドル 150円。

## 3. 来期上期の見積

前提は三つ。

1. DAU。今期上期の平均は 18.0万。来期上期は、プロデューサーの事業計画の前提である 17.0万を使う。
2. 費用のうち、DAU に比例して動くのは6割、動かないのは4割（今期の 12か月の実績から出した）。
3. 為替は1ドル 155円で置く（財務から来期の予算用として示されている値）。

計算（1ドル 150円の基準）。

| 項目 | 月額 |
|---|---|
| 通常月：420万円 ×（0.4 ＋ 0.6 × 17.0 ÷ 18.0） | 406万円 |
| 予約割引：常時動かしている 150万円分に 28% | −42万円 |
| 通常月の計 | 364万円 |
| 8月の上乗せ（今期の 86万円を参考に 90万円） | ＋90万円 |
| 8月の計 | 454万円 |

- 上期の合計（150円の基準）：364万円 × 5か月 ＋ 454万円 ＝ 2,274万円
- 155円に直すと：2,274万円 × 155 ÷ 150 ＝ 2,349.8万円
- 予備 5%：117.5万円
- 計 2,467.3万円。端数を切り上げて、2,470万円。

今期上期の実績 2,606万円に対して、136万円（約5%）の減。

## 4. 予約割引について

- 対象は、データベースとアプリケーションサーバーのうち、常に動かしている分（月 150万円分）。DAU が 12万まで下がっても使い切る量に限った。
- 月の支払いは 150万円 × 0.72 ＝ 108万円。1年で 1,296万円。前払いは無く、月払い。経理に手続きを確認済み。
- 版元との運営の契約は 2028年3月まで（今年9月に更新済み）。予約の期間は、この中に収まる。

## 5. 見込みが外れたとき

- 為替。1ドル 165円まで動くと、上期で 151.6万円の増。予備の 117.5万円を 34.1万円超える。超える分は、ログの保管期間の短縮（月 12万円の減。検証は済んでいる）で吸収する。
- DAU。計画を上回ると、1万人あたり月 14万円ほど増える。売上も増えるので、扱いはプロデューサーと決める。
- 毎月の実績は、翌月の5営業日までにプロデューサーに共有する。予備を使い切る見込みになった時点で、その月のうちに上げる。

- 予約割引の契約の手続きは、経理に確認済み。
