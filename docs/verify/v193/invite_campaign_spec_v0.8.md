# フレンド招待キャンペーン 仕様書 v0.8

作成：プランナー（3年目）　最終更新 2026-11-13

## 1. 目的

招待を通じた新規のインストールを増やす。目標は、キャンペーンの期間中に 3,000件。

## 2. 期間

2027-02-01（月）〜 2027-02-28（日）

## 3. 仕組み

- プレイヤーごとに、招待コードを発行する。
- 招待された人が、コードを入力してゲームを始め、チュートリアルを終えると、招待が成立する。
- 成立すると、両方に報酬を渡す。

## 4. 報酬

| 対象 | 報酬 |
|---|---|
| 招待した人 | 石 300個（成立1件ごと） |
| 招待された人 | 石 500個、SR 確定チケット 1枚 |
