# ギルドボス　仕様書（完成版）

プランナー（5年目）　企画リードのレビュー済み（11/19）

## 1. 目的
ギルドに入っていない人に、ギルドに入ってもらう。
- 現状：アクティブなプレイヤーのうち、ギルドに入っていない人は 55%
- 目標：実装から2か月で、45% に下げる

## 2. 概要
ギルドのメンバー全員で挑む、週替わりの大型のボス。倒すと、ギルドの全員に報酬が配られる。

## 3. ルール
- 挑めるのは、ギルドに入っている人だけ
- 1人1日3回まで挑戦できる。与えたダメージは、ギルドで合算する
- 1週間で倒しきると、ギルドの全員に報酬
- ボスの HP は、ギルドの人数に応じて変わる

## 4. 報酬
- 討伐の報酬：限定の強化の素材、ギルドコイン 500
- 貢献の上位3名（ギルド内）：限定の称号

## 5. ギルドに入っていない人への見せ方
- ホームに、「ギルドに入ると、ギルドボスに挑めます」というバナーを出す
- バナーを押すと、ギルドの一覧の画面に移る

## 6. 計測
ギルドに入っていない人の割合（週次）。ギルドボスに参加した人の割合（週次）。

## 7. 日程
実装の着手 11/25、リリース 1/20。
