# サーバー費用の削減　結果報告

2026年11月19日　エンジニアリード

## 1. 合意していたこと
9月の期初に、部長・プロデューサーと合意した内容です。
- 10月末までに、月額のサーバー費用を、8月の実績（1,240万円）から 15%下げる（1,054万円以下）
- 条件：応答時間とエラー率を悪化させない

## 2. やったこと
1. 常時起動していたアプリサーバーを、時間帯と負荷で増減する設定に変更（9/16 に適用。9/11 に、過去最大の同時接続の 150% で負荷試験を実施し、増減が追いつくことを確認）
2. 使われていなかった検証環境 6つを停止（9/9。各チームに利用の有無を確認済み）
3. データベースを、1年の予約購入に切り替え（10/1 から）

## 3. 結果
10月の実績：月額 1,021万円（8月比 −219万円、−17.7%）。目標を達成しました。

| 施策 | 削減額（月） |
|---|---|
| 1. 増減の設定 | −118万円 |
| 2. 検証環境の停止 | −41万円 |
| 3. 予約購入 | −60万円 |
| 計 | −219万円 |

## 4. 条件の確認
| 指標 | 8月 | 10月 |
|---|---|---|
| 応答時間（95パーセンタイル） | 412ms | 405ms |
| エラー率 | 0.021% | 0.019% |

10/12〜10/18 のイベント期間（最大同時接続は、8月のイベントの 104%）も、増減の設定が追いつき、障害はありませんでした。

## 5. 今後
- 予約購入は1年契約のため、来年9月に、継続するかを見直します（担当：私。チームの予定表に登録済み）
- 来期の予算の前提として、月額 1,021万円を、プロデューサーに 11/5 に共有済みです
- 11月からは、月次の定例での数字の報告に戻します
