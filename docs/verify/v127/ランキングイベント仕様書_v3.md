# ランキングイベント　仕様書 v3

プランナー（6年目）

## 目的
上位のプレイヤーの、イベント期間中の毎日のプレイを増やす。
指標：上位 5,000人の、期間中の1日あたりのプレイ時間（今は平均 52分。目標 65分）。

## 期間
12/26〜1/5（11日間）

## ルール
- イベント専用のステージで得たポイントの累計で、順位を決める
- 1日ごとに、その日のポイントの上位に「デイリー報酬」を出す
- 最終の順位で「総合報酬」を出す

## 報酬
- デイリー報酬：その日の上位 1,000人に、石 200個
- 総合報酬：1〜100位に限定の称号と★5 の確定チケット、101〜1,000位に★5 の確定チケット、1,001〜5,000位に石 1,500個

## v2 からの変更（v3）
- デイリー報酬の人数を、500人から 1,000人に広げた
- 期間を 14日から 11日に短くした（年始の休み明けの前に終えるため）

## 計測
期間中の、上位 5,000人の1日あたりのプレイ時間を、毎日見る。
