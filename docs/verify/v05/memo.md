## 4. 持ち込みで届くか
- 守るものを動かしていない。
- 効いている：監修依頼の段。送付日・戻し期限が両方あり①に効く。新イベント行、2体完了行も事実どおり。社内補足の「監修済みから変更なし」「確認期間に間に合う」は②の材料として効く（ただし版元文面に入っていない）。
- 成り立っていない：「1体は最終調整中」。素材未着の状態を最終調整中と書くのは事実と違う。
- まだ無いもの：遅延の事実＋影響なしの記述（本人の役割、送付前）。11/19 未着時の一報（本人の役割、11/19 当日）。
- 逆に働く要素：「最終調整中」。11/19 がずれた時点で、版元からは 11/13 に知っていて伏せたと見え、②を壊す。
- 全体：①届きうる・届いている。②このままでは届きえない（理由：上記）。一行直せば届きうる。次の一歩（送付）は直すまで踏めない＝送ると取り返せない。直せば今日送れる。③本件の文面は影響しない。
- 責任：遅延をディレクターに共有し、部長にも補足で上げている＝検知時点で上げている。経路の飛ばしなし。
- 決めたこと：置き換え文案はこちらで決めて渡す。外注先の事情は版元文面に出さない。「概ね順調」は遅延を書けば整合するので触れない。
