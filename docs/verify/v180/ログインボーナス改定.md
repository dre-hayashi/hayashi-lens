# ログインボーナスの改定　仕様書

プランナー（4年目）　企画リードのレビュー済み（11/20）

## 1. 目的
7日連続でログインする人を増やす。
- 指標：月のうち、7日連続のログインを1回以上達成した人の割合
- 現状：34%　目標：40%

## 2. 今の仕組み
毎日ログインすると、その日の報酬がもらえる。7日で1周（合計で石 700個）。1日休むと、1日目に戻る。

## 3. 変更
- 7日で1周は変えない。合計も 700個のまま
- 配り方を変える。今は毎日 100個ずつ。変更の後は、1〜6日目は 50個ずつ、7日目に 400個
- 1日休んでも、1日目には戻らない。続きから再開できる（月に2回まで）

## 4. 狙い
7日目の報酬を大きくして、最後まで続ける理由を強くする。
休んでも戻らないようにして、途中であきらめる人を減らす。

## 5. 計測
7日連続のログインを達成した人の割合（週次）。

## 6. 日程
12/1 実装の着手、1/13 リリース。
