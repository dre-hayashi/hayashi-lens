# スタミナの仕組みの見直し　仕様書 v2

プランナー（4年目）

## 目的
1日に2回以上遊ぶ人を増やす。
指標：1日に2回以上ログインした人の割合（今は 38%。目標 45%）。

## 変更の内容
- スタミナの上限を 120 から 200 に上げる
- 回復の速さは今のまま（5分で1）
- あふれた分を、最大 100 まで「予備」にためられるようにする
- 「予備」は、1日1回だけ、ボタンで本体に移せる

## v1 からの変更（前回の指摘への対応）
- 上限を上げる理由を書いた：上限が 120 だと 10時間であふれる。寝ている間や仕事の間にあふれるのがもったいない、という声が多い

## 画面
ホームのスタミナの表示の横に、「予備」の数と、移すボタンを置く。
