# 作業メモ
## 手順1
- 返す相手：書いた本人（デザイナー2年目）。部長宛ての相談を、出す前に持ってきたものとして読む。
- 求めていること：助言（どうしたらよいか）。本人は「自分が悪い」と受け止め、相談してよいか迷っている。
- 誰に届くか：部長（社内）。リード本人が当事者なので、リードを通す経路は成り立たない。部長に上げるのは正当な経路。
- 席：F 上司・育成者／チームの体制を預かる部長の席。場面：consult。副知識：労務の範囲（ハラスメント防止、相談窓口、産業医）。

## 手順2 土台の事実（すべて資料から）
- 期間：約2か月（「この2か月ほど」）
- 頻度：毎日のように
- 場：皆の前
- 言葉：「何年やってるんだ」「向いてないんじゃないか」
- 指示の中身は正しいことが多い（本人の受け止め）
- 影響：朝、会社に来るのがつらい
- 本人がどうなりたいか：未記載（本人にしか分からない。次の往復で聞く）
- 判断は事実の答えで変わらない：皆の前で適性を否定する言葉が毎日続くことは、指示の正しさと別の問題。今も続いており、部長へ今日届けるべき。→一問を待たずに返す。

## 手順3
- 結果：本人が心身を損なわず働き続けられること（体制）。部長が事実を把握し、止める決定を取れること。チームの指導が直しの中身で回ること。
- 守るもの：会社のハラスメント防止の規定。人を責めず仕組みを正す。人の評価と処遇はしない。
- 届くまで：(1)この相談が今日部長に届く。(2)部長が事実を確かめられる材料（日時・言葉・居合わせた人）。(3)体調がつらいなら産業医・相談窓口。(4)本人の望みを言葉にする。
- 役割：本人＝事実を伝える・記録・望みを言う。部長＝事実確認と止める決定。リードの指導の在り方は部長とリードの間の事柄。産業医・相談窓口＝心身の相談。

## 手順4
- 効いているもの：下書きが事実で書けている。期間・頻度・場・言われた言葉そのもの・自分への影響。程度の言葉で済ませていない→(1)(2)に効く。
- 成り立っていない説明：「指示が正しいから自分が悪い」。指示の正しさと、皆の前で適性を否定する言い方は別。成り立たない。
- まだ無いもの：(2)日時・居合わせた人の記録（本人）。(4)望み（本人）。(3)体調の相談（産業医の役割）。
- 全体：届きうる。まだ届いていない。送る一歩は今踏んでよい（記録・望みは送った後でも足せる）。迷って送らないことが一番届かない。
- 責任：本人は役割を果たしている（検知して上げようとしている）。

## 手順5
- 根：「自分が悪い」という受け止めが、送るのをためらわせている。
- 返す：全体の答え（今日このまま送ってよい）／成り立たない説明（指示の正しさと言い方は別）／効いているもの一つ（言われた言葉そのままを書けている）／今すぐ：体調がつらければ産業医・相談窓口も使える（今も続く件なので次に回さない）。
- 次の往復で返す：日時・居合わせた人のメモ。本人がどうなりたいか。
- 返さない：リードの評価・処遇。部長の対応の約束。
- 面：上司・育成者。責めず、安心して上げてよいと伝える口調。判断は言い切る。

## 出す前の確認（fail → 直した）
- なぜ：産業医・相談窓口に理由が無い→「つらさは我慢で回復しない、早いほど戻りやすい」を足した。
- 並び：「部長は…聞き返さずにつかめます」が部長の行動の約束→文面が何を伝えているかの判断に言い直した。
