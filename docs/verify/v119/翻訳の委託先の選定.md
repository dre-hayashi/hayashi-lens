# 翻訳（英語・繁体字）の委託先の選定　承認依頼

2026年11月20日　PM

## 1. 依頼
来年1月からの、ゲーム内のテキストの翻訳の委託先を、B社に決めたい。
費用は月 120万円で、来期の予算の枠（月 130万円）の中です。プロデューサーには 11/18 に説明し、了承をもらっています。

## 2. 経緯
今の委託先（A社）は、12月末で契約が満了します。この半年、納期の遅れが5回あり、11/5 に、更新しないことを先方と合意しました。

## 3. 比べた3社

| | B社 | C社 | D社 |
|---|---|---|---|
| 月額 | 120万円 | 98万円 | 135万円 |
| ゲームの翻訳の実績 | 12タイトル | 2タイトル | 20タイトル |
| 試しの翻訳（同じ原稿 3,000字）の評価 | 英語 4.5 / 繁体字 4.3 | 英語 3.6 / 繁体字 3.1 | 英語 4.6 / 繁体字 4.4 |
| 納期（月2回の更新、各 2万字） | 5営業日 | 7営業日 | 5営業日 |
| 専任の担当 | あり | なし | あり |

評価は、現地のプレイヤー各3名（計6名）に、5点満点で付けてもらいました。

## 4. B社を選ぶ理由
- 品質は D社とほぼ同じで、月 15万円安い
- C社は最も安いが、試しの翻訳で、キャラの口調の取り違えが複数あり、今の進行（5営業日）にも合わない

## 5. 切り替えの進め方
- 12/1〜12/20：用語集と、キャラごとの口調の資料を B社に渡し、12月の後半の更新分を、A社と並行して訳してもらう（並行の分の費用 60万円は、今期の予備費から。プロデューサー了承済み）
- 1月の最初の更新から、B社のみ

## 6. うまくいかなかったとき
- 12月の並行の結果が、評価 4.0 を下回ったら、D社に切り替える（D社には、1月開始が可能なことを 11/17 に確認済み。費用は予算の枠を月 5万円超えるので、その場合は改めて相談します）
- 契約は、最初の3か月は、1か月前の通知で解約できる条件です
