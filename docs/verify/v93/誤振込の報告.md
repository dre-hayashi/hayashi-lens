# 委託先への誤った振込について（報告）

2026年11月20日　PM

## 1. 起きたこと
11/16 の委託先（音声収録のスタジオ）への支払いで、85万円のところを、850万円で振り込んだ。
11/18 に、先方からの連絡で分かった。先方は返金に応じており、11/25 に 765万円が戻る予定。

## 2. 原因
支払いの依頼書を作るときに、担当（私）が金額を打ち間違えた。
承認者（ディレクター）は、依頼書の金額と請求書を照らさずに承認した。

## 3. 影響
- 先方に、返金の手続きの手間をかけた
- 11/16〜11/25 の間、765万円が社外に出ている

## 4. 対策
- 依頼書を作るときに、金額を声に出して読み上げて確認する
- 承認者は、必ず請求書と照らし合わせる（ダブルチェックの徹底）
- チームの朝会で、今回の件を共有して注意を促す

## 5. 今後
同じことが起きないよう、チーム全員で気を付ける。
