# 作業メモ
## 手順1
- 返す相手：CS 担当（2年目、メンバー層）。部長宛ての質問を本人に返す。
- 求めていること：確認（社内の目標値という事実を教えてほしい）。目的は月次報告に目標との差を書くこと。
- 届く先：月次報告（社内。リード・部長が読む）。
- 席：部長の席。面：上司・育成者。場面：報告（月次報告の準備）。モード：壁打ち。
## 手順2 土台
- 立っている事実：本人は一次返信時間の目標値を知らない。リードは今週休暇（本人の言葉）。月次報告に目標との差を書きたい（本人の言葉）。
- 目標値そのものは会社の中にしか無い事実。こちらは持っていない。言い切らない。確かめ先：タイトルの CS 運用ルール・マニュアル、過去の月次報告。
- 報告の締切、過去報告の様式は未確認。答えで判断は変わらない（どこを見るか、数字を自分で置かない、は締切に依らない）ので聞かない。
## 手順3
- 結果：月次報告が、決まった目標に対する実績の差を正しく示すこと。
- 守るもの：目標値は決めた役割のもの。担当が推測で置かない。
- 届くまで：目標の出どころの文書を見つける → 数字と出どころを報告に書く → 差を出す。無ければ「目標未設定」と書き、設定はリードへ。
- 役割：探して書くのは本人。目標の設定はリード（セクションの品質基準）。
- 経路：リードを飛ばして部長に来た理由は休暇＝権利の履行で正当。経路の指摘はしない。
## 手順4
- 効いているもの：目標との差を報告に書こうとしていること。月次報告の役目に効く。
- 全体：届きうる。まだ届いていない（目標値の出どころが無い）。次の一歩（報告に数字を書く）は、出どころを確かめるまで踏めない。
- 本人の責任：果たしている（不明点を、リード不在時に上に聞いている）。
- まだ無いもの：目標値とその出どころ → 本人が探す。見つからなければ未設定と書く。設定はリード。
## 手順5
- 返す：(1) こちらは数字を持っていない、どこで確かめるか（運用ルール・過去の月次報告）、出どころも報告に書く。(2) 見つからなければ自分で数字を置かず「目標未設定」と書き、リード復帰後に決めてもらう。理由：根拠の無い目標で差を出すと読む側が誤る。(3) 効いているもの：目標との差を書くこと。
- 返さない：締切の確認、報告の様式、目標値の妥当性。
- 面：上司・育成者。短い往復。
