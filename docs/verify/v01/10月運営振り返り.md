# 10月 運営振り返り

作成：ディレクター　2026/11/5
確認：プロデューサー（数字は 11/4 に確認済み）

## 1. 結果
- 売上：計画 2億円 → 実績 2億600万円（計画比 103%）
- MAU：計画 32.0万人 → 実績 32.4万人
- 課金率：計画 4.1% → 実績 4.2%

## 3. 振り返り
- ハロウィン限定は、新キャラクターが原作の人気上位だったことに加え、開始3日間の購入者数が計画の 1.2倍だった。後半は計画どおり。
- 復刻は計画を 400万円下回った。開始日（10/8）がハロウィン限定の後半と重なり、復刻の購入者のうちハロウィン限定も買った人は前回の復刻より少なかった（前回 46% → 今回 31%）。石を先にハロウィン限定で使い切った人が、復刻に回らなかったと見ている。
- 復刻の未達分は、ハロウィン限定の上振れ 900万円の中に収まっている。

## 4. 不具合
- 10/14、イベント報酬のお知らせ文に誤記があった（石 300個と書くべきところを 500個と表記）。配布された数は正しく 300個。当日中にお知らせを訂正し、問い合わせは 12件。補填は行っていない（配布は正しいため）。
- 原因：お知らせ文が、設定値の照合の対象に入っていなかった。
- 対策：10/20 から、お知らせ文の数値を、設定値と同じ照合表で、担当と別の人が照合している。11/5 までの更新 3回で誤記はない。

## 5. 11月への反映
- 復刻ピックアップの開始日を、目玉のピックアップの期間と重ねない。11月は 11/10（火）開始の予定だったものを、目玉が終わる 11/17（火）の開始に変えた。プロデューサーと 10/28 に決定済み。11月の計画 2億円は変えていない。
