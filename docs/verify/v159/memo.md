# 作業メモ
- 返す相手：デザインリード（部長宛の相談を、出す前に持ってきたものとして読む）。
- 求めていること：相談（時間がほしい）。何を決めてほしいか・どうしたいかは書かれていない。
- 届く先：社内（部長）。外には出ない。
- 席：部長（上司・育成者として相談を受ける席）。場面：consult.md、advice.md の土台。

## 手順2 土台
立っている事実（material.md より）
- 2026-11-21 時点、本人はチームの雰囲気が悪いと見ている（程度の言葉。実体は「朝会の発言が減った」）。
- 先週、企画とデザインの間で仕様変更をめぐる言い合いがあった。
- 年末に向けて忙しくなる。本人はそれを気にしている。

立っていない事実
- 本人の結論（原因をどう見ているか、リードとして何をするつもりか、部長に何を頼みたいか）。← 最優先。consult の土台。
- 言い合いの中身：何の仕様変更か、誰が決めた変更か、決着したか、ディレクター/PM は関わったか。
- 年末の具体的な予定。
- 「チーム」の範囲（デザインセクションか、プロジェクト全体か）。

役割（roles.md）
- セクションリーダー：チーム内の風通し、建設的な意見交換ができる環境の構築・維持。現場の状況をマネジメントに伝える結節点。→ 本人の役割。
- 仕様の優先順位・承認：ディレクター。チーム健全性・コミュニケーションの齟齬の除去：PM。→ 本人に求めない。後の往復で経路として扱う。

一問の前に言い切れる判断（答えで変わらない）
- 忙しくなる前の今、上げてきたのは正しい。繁忙期に入ると、立て直す余地が減るため。（効いているもの）
- 「雰囲気が良くない」だけでは、部長は打つ手を決められない。チームが話せる状態を保つのはリードの仕事なので、リードとしての見立てと打ち手を先に持つ必要がある。

一問：リードとして、どう手を打とうと考えているか。

## 手順5（この回）
返すと決めたもの：上の判断二つ、一問。
次の往復で返すもの：言い合いの中身（仕様変更の決め方と経路、ディレクター/PM の関与）、年末の予定との関係、腹案。
返さないもの：朝会の運営の細部、個人の評価に関わること。
面：上司・育成者。決めない。全部を一度に渡さない。
