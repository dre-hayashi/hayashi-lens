# ガチャの天井の見直しの提案

プランナー（5年目）

## 提案
ピックアップのガチャの天井（必ず手に入るまでの回数）を、300回から 200回に下げる。

## 理由
- 天井まで引く人は、ピックアップを引いた人の 4% にとどまっている
- 「300回は遠すぎる」という声が、アンケートの自由記述で 3番目に多い
- 天井が近くなれば、途中まで引いた人が「あと少し」と感じて、最後まで引く人が増えると考える

## 見込み
天井まで引く人が、4% から 8% に増える。1回のピックアップあたりの売上は、5% ほど増える。

## 進め方
1月の最初のピックアップから始める。お知らせは、12/20 に出す。
プロデューサーには、まだ話していません。
