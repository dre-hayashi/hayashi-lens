# 作業メモ
## 手順1
- 返す相手：プロデューサー（部長宛ての承認依頼を、出す前に持ってきたものとして読む）
- 求めていること：承認（来期体制 企画3→2名、設定作業の外部委託 月40万円）
- 届く先：社内（部長）。運営中タイトルのイベント品質を通じて顧客にも及ぶ
- 席：A 承認者（scenes/approval.md）。モード：壁打ち（Slack）

## 手順2 土台（資料から）
- 計画：来期 企画3→2名、1名を新規タイトル準備へ（資料1文目）
- 手段：毎月の定型イベントの設定作業を外部委託（2文目）
- 費用：月40万円、「1名分の人件費より下がる」（3文目）
- 経路：ディレクター・企画リード合意済み（4文目）→ 飛ばされた役割なし
- 事業成績への見込み：明示なし。「2名で回せる」＝イベントの量と質を維持する前提と読む。根拠（工数内訳）は資料に無い → 根拠の節で返すもの
- 比べる基準：「1名分の人件費」比較はタイトル単位。会社としては人件費は消えず新規側へ移るだけ → 私が知識で決められる（問わない）

## 手順3
- 結果：(1) 運営タイトルの来期計画（毎月イベントの実施と売上、設定ミスによる事故なし＝顧客の信頼）(2) 新規タイトル準備への1名配置 (3) 事業部の来期P/L
- 守るもの：イベント設定の品質（事故を出さない）、業務委託・下請法の定め、労働時間
- 届くまで：工数内訳（設定の割合、委託後に残る指示書作成・やり取り・設定確認）／委託先選定・契約・立ち上げ（来期開始の2〜3か月前まで）／並走で委託先の質を確かめる／確認工程の設計／腹案（委託の質不足・2名で回らないとき）
- 役割：P＝予算・体制方針・委託契約・腹案・数字。企画リード＝工数内訳と確認工程。ディレクター＝イベント品質。部長＝承認

## 手順4
- 守るものを動かす案ではない
- 効いている：定型作業を外に出して1名を空ける手は(2)に効く。タイトル単位ではコスト減。D/リード合意済みで経路は通っている
- 説明：「1名分の人件費より下がる」はタイトル勘定では成立、会社としては月40万・年480万の純増 → 私が決めて伝える
- 「2名で回せる」：根拠なし。委託しても指示書と確認が社内に残るのは知識で言える。2名で足りるかは内訳次第 → 本人の役割（リードと出す）
- まだ無いもの：①工数内訳（確認含む）→本人、承認前に要る ②腹案→本人、承認前に要る（approval.md 条件） ③費用の基準→私が決めた
- 全体：届きうる／まだ届いていない／次の一歩（承認）はまだ踏めない：①②は移動・契約後では取り返しにくい
- 役割の責任：体制方針・委託は役割どおり。承認依頼として根拠と腹案を持つのは P の責任で未充足
