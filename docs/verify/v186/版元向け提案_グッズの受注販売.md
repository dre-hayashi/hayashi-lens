# ご提案：ゲーム内でのグッズの受注販売

2026年11月　第1ゲーム運営事業部

## 1. ご提案
ゲームの中から、作品のグッズを受注で販売する仕組みを、来年の夏から始めたく、ご相談いたします。

## 2. 内容
- ゲーム内のショップに、グッズの受注のページを設ける（アクリルスタンド、タペストリーなど。年4回）
- 製造と発送は、当社の提携先が行う
- 絵柄は、ゲームのために描き下ろしたものを使う

## 3. 貴社にお願いしたいこと
- グッズの商品化の許諾
- 絵柄の監修

## 4. 条件
- 売上の 8% を、ロイヤリティとしてお支払いする

## 5. 期待される効果
- 作品のファンの方に、新しい楽しみをお届けできる
- ゲームの利用者の増加
