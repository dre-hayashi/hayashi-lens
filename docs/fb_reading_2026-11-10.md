## 2. なぜの掘り下げ（5Why。一つの返答に「なぜ」を問い、その答えにまた「なぜ」を問う）

初版はここが間違っていた。別々のコメントに一つずつ「なぜ」を付けて並べただけで、鎖になっていなかった。二版も、途中の段で別のコメントへの問いに乗り換えていた（ケース7 の四段目、ケース8 の四段目）。三版で、各段の問いを、直前の答えへの「なぜ」だけにした。

各段の答えに付けた根拠の種別：
- （言葉）本人の言葉が記録にある。
- （認めた理解）Claude の理解で、本人が「分かっている」「合っている」「いいんじゃないでしょうか」と答えたもの。
- （推察）Claude が推し量っただけのもの。主張しない。7 章に仮説として分けた。

### ケース10：組み直してきた PM への返し（立場：契約と交渉に責任を持つ人）
出発点：穴の残る方針に責める返事を返したスキルに、本人は「突き放すのは違う」「出口や合意形成に必要なステップとどうしてほしいか？を簡素に伝える」と言った。
1. なぜ、簡素に伝えるのか。→「大筋は合意できうるロジカルな内容提示」で「残りの小さな点を解決すれば完了となる」から。（言葉）
2. なぜ、小さな点を解決すれば完了になるものには、簡素でよいのか。→ 返す目的は、PM が残りを直して完了まで進むこと。それに要るのは、何を直せば完了か、どう進めるか、だけだから。（推察。支えは言葉「出口や合意形成に必要なステップ」）
3. なぜ、返す目的が、PM が完了まで進むことなのか。→ 見ているのは資料ではなく、書いた人が役割の責任を果たしているか。返すのは、果たした状態で持ってこられるようにするためで、指摘の列挙は手段だから。（認めた理解。10/20）
4. なぜ、部長が直すのではなく、PM 自身が果たした状態にすることが目的なのか。→ 任せた仕事だから。「任せる以上、自分と同等は無理がある。80点以上なら合格などの線引きはしてしかるべき。本質は、ベストを目指した結果80点に留まったのか、最初から80点に置いたのかを問うている」。（言葉。10/22）
5. なぜ、ベストを目指したかどうかを問うのか。→ 仕事は信頼で成り立ち、信頼は役割の責任を果たしているかで決まるから。（認めた理解。10/20）

行き着いた所：返し方を決めているのは、穴の数ではなく、相手が役割の責任を果たそうとして持ってきたか。ケース10 の PM は、前回の指摘を受けて筋道を立てて組み直してきた。これをベストを目指した動きと読むのは推察。

### ケース7：売上未達のリカバリ案への返し（立場：計画を承認した事業責任者）
出発点：原因を問う返事を返したスキルに、本人は「本質は届かない領域を埋めるアイディアで、その有無や計画の見通しを問う」「再発防止の話は別口」と言った。
1. なぜ、原因ではなく、埋める手の有無と見通しを問うのか。→ 持ち込みは「乖離した実績と見込みをどうリカバリをしていくのか？という計画の話」だから。（言葉）
2. なぜ、リカバリの計画の話では、原因より埋める手が先なのか。→ 原因が分かっても今の差は埋まらない。原因は次の計画に効くもので、今の決定には効かないから。（認めた理解。11/09「1〜4はあっている」）
3. なぜ、今の差を埋めることを先に置くのか。→ 計画の数字は合意で、合意した内容に全力を尽くすのが責任だから。（言葉。10/20「合意済みの内容に沿って全力を尽くしていないのが透けて見える」）
4. なぜ、全力を尽くすことを責任として求めるのか。→「どれだけ頑張ったかは重要ではなく、何を成したかでしか評価されない」から。（言葉。10/20）
5. なぜ、成したことでしか評価しないのか。→ 仕事は信頼で成り立ち、信頼は役割の責任を果たしているかで決まるから。（認めた理解。10/20）

行き着いた所：計画からずれた責任者に問うのは、合意した数字に手を尽くしているか。本人の三つの問い「穴をどう埋めるのか、それは可能なものなのか、ダメな場合はどうなるのか」は、その確かめ方。前倒しも「前倒しして何をするのか？」でこの問いに繋がる（言葉。11/09）。届かない分は「埋められるところは埋めた上で埋めきれない確定損失額の見通し情報を出させる」（言葉）。

### ケース8：委託先への回答方針への返し（立場：契約と交渉に責任を持つ人）
出発点：8% と 10% の根拠を問う返事を返したスキルに、本人は「そんなに突っ込むポイントではない」と言った。
1. なぜ、突っ込むポイントではないのか。→「落とし所の初回設定としては悪くない」から。直すとしても「+5％を実績として皮切りにし、8％→10％と刻むほうがより良いな、ぐらい」。（言葉）
2. なぜ、悪くない設定なら、根拠を問わないのか。→ 落とし所は、証明する数字ではなく、過去実績と相手の要求の間に置く判断で、PM の置き方は任せた案として外れていないから。（認めた理解。11/04「いいんじゃないでしょうか」）
3. なぜ、外れていなければ、それ以上は問わないのか。→ 返す目的は、交渉が「我々の事業目線でより望ましい形になる」こと。根拠を出させても、そこには近づかないから。（言葉＋推察。「近づかない」が推察）
4. なぜ、望ましい形になることが、返す目的なのか。→ 契約と交渉の責任者は、払う費用に対して「我々が何を得るか」に責任を負うから。（言葉。10/20）
5. なぜ、その責任を、PM の方針への返しで果たすのか。→ 交渉の席に着くのは PM だから。部長の責任は、PM が望ましい形で着けられる状態で交渉に出ることで果たされる。（推察。支えは 10/22「任せる以上」、10/20 の認めた理解）

行き着いた所：指摘するのは、相手が目的に届くのに効くものだけ。同じケースの中で確かめられる。「決裂時の手がない」には「これは良い観点」、相手の主張には「社内契約している人たちと比べて」調べる、と本人は言った。どちらも、こちらの言い分をぶつけて協議するのに効くもの。

## 4. なぜ機能しないのか（スキルの動きへの「なぜ」）

出発点：筋の通った持ち込み（ケース10）に、責める返事を返した。
1. なぜ、責める返事になったか。→ 返事が、不備の指摘だけで組まれたから。作業メモでは「狙いと組み立ては噛み合っている」と答えていたのに、その答えは返事に入らなかった。（ケース10 の作業メモと返事）
2. なぜ、噛み合っているという答えが返事に入らないのか。→ 返事を組む手順が、返事に上げるものを不備だけで並べているから。考え方の側には「言えればその線で認める」「評価は文章全体の在り方で下し、一箇所を切り出さない」が書いてある。返事を組む手順は、それを使う所を持っていない。（スキル本体の手順6 と、絞り込みの決まりの「上げる」六項目。六つとも不備）
3. なぜ、手順が不備だけを並べているのか。→ 手順を作ったときの材料が、全部、不備のある持ち込みへの本人の判断だったから。（10/20 の各場面、ケース1〜5）
4. なぜ、材料が不備のある持ち込みばかりだったのか。→ 例題を作った Claude が、穴を置いた設定だけを作ったから。（10/21 の設計文書。各ケースに「持ち込みの状態」として足りないものを置いている）
5. なぜ、穴を置いた設定だけを作ったのか。→ スキルの仕事を「持ち込みの問題を見つけて返すこと」と捉えていたから。目的は、持ち込んだ本人が役割の責任を果たした状態になること。果たそうとしている相手を完了まで進ませることは、その目的の中にある。

行き着いた所：判断の軸はスキルにある。返事を組む手順が、不備のある持ち込みへの判断だけから作られていて、軸のうち「認める」「全体で評価する」を返事に繋いでいない。

## 7. 仮説（Claude の推察のみ。主張に使わない。本人に問わない）

1. ケース10：小さな点を解決すれば完了になる持ち込みへの返しは、PM が残りを直して完了まで進むためのもの。要るのは、何を直せば完了か、どう進めるか、だけ。
2. ケース10：前回の指摘を受けて筋道を立てて組み直してきたことを、ベストを目指した動きと読む。
3. ケース8：部長の責任は、PM が望ましい形で着けられる状態で交渉に出ることで果たされる。根拠を出させても、そこには近づかない。
