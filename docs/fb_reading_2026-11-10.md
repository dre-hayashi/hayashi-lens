## 2. 立場と、なぜの掘り下げ

鎖の各段に、本人の言葉があるものは（言葉）、無いものは（推論）と付けた。推論の段は 3 章の項目に使っていない。

### ケース7：事業責任者（月次の計画を承認した人）として
1. なぜ原因の話に進むのを止めたか → 持ち込みは未達の穴埋めの承認依頼で、今決めるのは計画との差をどうリカバリするか（言葉「乖離した実績と見込みをどうリカバリをしていくのか？という計画の話」）。
2. なぜ再発防止を別口にするか → 目的の違う二つを同じ対話に載せると、本題が進まない（言葉「問題の切り分けができていない」「指摘にとどめて本題に集中」）。
3. なぜ前倒しを否定しないか → 手は、計画の中で果たす役目で見る。前倒しは追加施策を作る時間を稼ぎ、欠損を直近で出さないための手（言葉）。
4. なぜ「埋める手の有無と見通し」か → 合意した計画への責任は、達成で果たす（言葉「本質は届かない領域を埋めるアイディア」。10/20「頑張るのは当たり前。何を成したかでしか評価されない」）。
5. なぜ埋めきれない額まで出させるか → 届かないなら、届かない事実を数字で上げるのが責任（言葉「ダメな場合はどうなるのか」「確定損失額の見通し情報」）。

### ケース8：契約と交渉の責任者として
1. なぜ 8%・10% を認めたか → 任せた案として、妥当な範囲にある（言葉「落とし所の初回設定としては悪くない」。10/22「任せる以上、自分と同等は無理がある。80点以上なら合格などの線引きはしてしかるべき」）。
2. なぜ「ぐらい」と言うか → 指摘に重さを付けている。+5% から刻む話は、良くなる助言であって、やり直しの理由ではない（言葉「そんなに突っ込むポイントではない」「より良いな、ぐらい」）。
3. なぜ先方の主張を PM に問わないか → 聞いても確かめられない問いは、相手を動かせない。確かめ方（社内の他契約と比べる）を知っている側が示す（言葉）。
4. なぜ決裂時の手は認めたか → 無いと、外れたときに動けない（言葉「良い観点」。10/20「腹案は重要」）。
5. 交渉で何を見るか → 事業目線で望ましい形を取りに行っているか。こちらの言い分を相手にぶつけているか（言葉）。

### ケース9：企画リードの上司（育成者）として
1. なぜ「資質がない」と見るか → リードの成果はセクションの成果。メンバーを能力の問題として切るのは、自分の成果を捨てること（言葉）。
2. なぜ「それぐらい」か → 全体としては相談の筋が通っており、返事で正せる範囲（言葉「大きくは問題ない」）。

### ケース10：契約と交渉の責任者として、組み直してきた PM に
1. なぜ突き放さないか → 相手は筋道を立てて大筋を組んできた。残りは小さい（言葉「大筋は合意できうるロジカルな内容提示」「残りの小さな点を解決すれば完了」）。
2. なぜ出口とステップとしてほしいことを伝えるか → 返事は、相手が完了まで進むためのもの（言葉「出口や合意形成に必要なステップとどうしてほしいか？を簡素に伝える」）。
3. なぜ「一長一短」か → 短くすると本人の返し方に寄るが、受け手にとっての良い点の評価と課題の見える化が弱くなる（言葉）。どちらを取るかは本人がまだ言っていない。

### ケース6（直した設定）：承認者として
1. なぜ返事を妥当としたか → 手前の前提（年間の見込み）が崩れているなら、そこで止めるのが先。自分の持つ観点（周年でそこまで膨らませられるか）は、その先で出ればよい（言葉「その一歩前の目線でせき止めている」「続く会話でひも解かれたりするならいい」）。

## 3. 磨いた項目（別の場面と照合したもの）

手順の検査：その項目を、別の場面に当てたら本人は何と言うかを言えるか。言えるなら、記録（docs/casestudies.md）の本人の言葉と突き合わせる。合ったものだけを残した。

### A. 評価は全体が先。指摘には重さがある
- 中身：本人は、持ち込みを見て、まず全体を決めている（大筋で合意できる／やり直し）。個々の指摘は、その全体を変えるものか、直せば済む小さな点か、良くなる助言かで重さが違う。
- 今回の言葉：ケース10「大筋は合意できうる…残りの小さな点を解決すれば完了」。ケース8「悪くない」「ぐらい」。ケース9「それぐらい。大きくは問題ない」。
- 別の場面：10/20 版元向け報告「評価は文章全体の在り方で」。ケース1「そんな端々のチェックですむような状態と内容じゃない。そもそも論として仕事をしていないと言われても仕方ないレベル」（全体が先で、端々は見ない、の逆向きの例）。10/22「80点以上なら合格などの線引きはしてしかるべき」。
- 根拠の種別：本人の言葉（五場面）。
- スキルに既にあるか：一文だけある（返す段の説明の末尾「評価は文章全体の在り方で下し、一箇所を切り出さない」）。手順の順番にはなっていない。

### B. 返事は、相手が完了まで進むためのもの
- 中身：返事で伝えるのは、何が済めば完了か、そのために要るステップ、相手にしてほしいこと。良い点（直さなくてよい所）と課題が、受け手に見えること。
- 今回の言葉：ケース10「出口や合意形成に必要なステップとどうしてほしいか？を簡素に伝える」「受け手目線で見ると良い点の評価や、課題点の見える化が弱くなる」。
- 別の場面：11/02 ラン C「出口なくねぇか？」。ケース2「あるべき方向性が見える状態に戻してあげるのが正しいFBだ」。ケース5「困ったらそのロジックに当てはめる逃げ道を用意してあげれば」。10/20 本質「指摘の列挙は手段」。10/27 目的と成果「どのように果たすべきかが相手に伝わる／理解される／納得されて次へ繋がるがセット」。
- 根拠の種別：本人の言葉（五場面）。
- スキルに既にあるか：目的の文としてはある。出口（何が済めば完了か）は 11/02 から「設計で答える箇所（未確定）」のまま。

### C. 問題を切り分け、今の本題に集中する
- 中身：一つの持ち込みに、目的の違う話が混ざっていたら分ける。今決めることに集中し、別の話は指摘にとどめて別口にする。
- 今回の言葉：ケース7「再発防止の話と、売上未達の損失穴埋めが同じ軸で対話されている」「問題の切り分けができていない」「指摘にとどめて本題に集中」。
- 別の場面：10/20 社内報告「策の承認と実行計画は別」。10/20 若手の助言「悩みは方向性であって内容ではない。未記載項目は踏み込まれない限り触れない」。ケース4「どこまで出すかの話ではなく、どのような権利体制なのか、という話」（問いを本題に立て直す）。
- 根拠の種別：本人の言葉（四場面）。
- スキルに既にあるか：個別の形ではある（承認と実行は別、方向性の段階で細部に触れない）。共通の動きとしては無い。

### D. 手は、目的に対して果たす役目で見る（既にある）

## 4. スキルのどこが、目的と成果からずれているか（事実）

目的（CLAUDE.md、10/27）：持ち込んだ本人が、自分の役割の責任をどう果たすべきかを理解し、納得して、次の持ち込みを変える。成果は、返事を受けた本人の次の行動。

スキル本体（11/02 の状態）と、実行時の作業メモから確かめたこと。

1. **全体を決める手順が無い。** 手順は、不備を拾う → 一つずつ「できている／いない」で答える → 返事にする、の順。全体の評価は、返す段の説明の末尾に一文あるだけ。11/02〜11/09 にこのやり方で走らせた 14 回（ケース6〜10 と走らせ直し）で、作業メモに「全体として合意できる／できない」を最初に書いた回は無い。
2. **不備の重さが消える。** 一つずつ二択で答えるので、「必要なものが無い」と「あるが詰めが甘い」が同じ「いない」になる。ケース10 の作業メモは「決裂時の手は狙いを守るか → 守らない」。本人は同じ箇所を「残りの小さな点」と見た。
3. **拾う項目が、場面を問わず全部当たる。** 資料に当てる項目は 13 群あり、全部が不備を探す問い。場面ごとのファイルにも見るものは書いてあるが、共通の項目が先に当たる。ケース8 の作業メモは、交渉の場面のファイル（最初のポジション、任せた案の目線）を開きながら、受け入れ条件を「自社側の根拠があること」と書いた。ケース7 は、計画からずれる場面のファイル（どう実現するかの計画を聞く）を開きながら、共通の項目「対策は原因を確実に除去するか」（不具合報告の見方）で原因を先に聞いた。
4. **返事に出口が無い。** 返事に上げるものの一覧は、全部が足りない点。認める点と、何が済めば完了かを置く場所が無い。同じ 14 回で、部分を認める言葉（「方向は合っています」「筋が通っています」）は出たが、全体として「これで進めてよい」に当たる返事は一度も出ていない。

A〜C は、この四つに一対一で当たる。A の欠けが 1 と 2、C の欠けが 3、B の欠けが 4。D〜F が効かなかったのも 1〜3 による。

## 5. 設計の骨子（合意を得てから作る）

何を受け、何を導き、何をどの形で返すか。場面ごとのファイル、知識、人物像は変えない。変えるのは手順の順番と、返事に上げるものの決め方。

- **受け取る、事実を確かめる**：今のまま。
- **全体を決める（新しく手順に置く）**：この人は、この持ち込みで、役割の責任を果たしているか。答えは二つ、大筋で合意できる／できない。材料は、スキルに既にある見るもの（結論、根拠の自己確認、検知した時点の報告、ダメだった場合、目線、目的）と、開いた場面のファイルの最初に見るもの。これらは一つずつ合否を出す項目ではなく、全体を決める材料として使う。
- **本題を決める（新しく置く）**：今この持ち込みで決めることは何か。目的の違う話が混ざっていれば分け、別の話は一言の指摘にとどめる。
- **不備に重さを付ける（今の二択を置き換える）**：拾った不備ごとに、全体の評価を変える／変えない。変えないものは、完了に要る／要らない。要らないものは返事に出さないか、助言として一言。本人が求めた「二択で答える」形はそのまま残る。
- **返す（順番を決める）**：最初に全体の評価。合意できるなら、良い点（直さなくてよい所）、完了に要る直しとしてほしいこと、何が済めば完了か。合意できないなら、その理由を一つと、何からやり直すか。最終決定は席の人に残す。
- **測り方**：ケース6〜10 の持ち込みを、資料を直さずにそのまま使う。見るのは設計どおりに動いたか（作業メモの最初に全体の評価があるか、不備に重さが付いているか、返事に出口があるか）。

本人の判断が要るのは一つ：B の「一長一短」。短い返事（本人の返し方に寄る）と、良い点と課題が見える返事（受け手が読んで分かる）のどちらを取るか。目的と成果の文（成果は受けた本人の次の行動）に従えば後者で、設計はそちらで組んである。

## 7. 第三者の検査と、作り直し（2026-11-10）

5 章の骨子で一度スキルを直し（efc03f6）、経緯を知らない第三者に、本人の言葉の写し・ケースの語・推論の混入・食い違いを検査させた。結果：

- 写しに近い語が三つ（「別口」「大筋で合意できる」「端々」）。
- 本人の言葉に根拠が無い文が七つ（「合意できないのは三つに当たるとき」と限る文、助言を分ける物差し、「良い点を言う」と定める文、場面で観点を絞る文、など）。
- スキルの中の食い違いが多数。特に、11/02 に本人が合意した「見立ての主体は、狙いと内容が噛み合っているか」を書き換えていた。返事に上げるものが四か所で違っていた。

これを受けて、11/02 の状態から作り直した。変えたのは次の四点だけ。場面ごとのファイル、観点の一覧、本人が合意した見立ての文は変えていない。

1. 論点に答えた後、持ち込み全体への評価を一つ決める。本人は、この持ち込みで役割の責任を果たしている／いない。評価は文章全体の在り方で下す。「いない」と決めるのは、スキルに元からある「差し戻しに相当するもの」に当たるとき。（A）
2. 「果たしている」と決めたら、残った論点を、完了に要る／要らない、で分ける。要るのは、その役割と場面で揃っていなければならないもの。要らないものは返事に出さない。（A）
3. 手は、目的に対して果たす役目で読む。本題を一文で書き、目的の違う話は分けて、短く触れるにとどめる。（C、D）
4. 返事は全体の評価から始める。「果たしている」持ち込みには、本人が次に何をすれば完了に進むかを伝える。出す前の監査も、これを見る。（B）

「良い点を言う」という決まりは置いていない。全体の評価が「果たしている」なら、返事の最初にそう言うことになる。「一長一短」の残り（課題をどこまで見える形にするか）は、本人の言葉がまだ無いので、スキルには入れていない。
