# 流れへの置き直し（2026-11-02）

本人の指示（11/02）：現行スキルの SKILL.md を合意済みの流れで書き直し、references の各項目を、流れのどの段で使うかが分かる形に置き直す。文言を足すのではなく、置く場所を決める。一段ずつコミットを分ける。流れが全部できるまで測らない。

流れ：受け取る → 土台の事実を一つずつ確かめる → 役割と状況から責任を導く → 論点を二択に落として答える → 相手・状況・中身で面を選ぶ → 返す。

## 直した問題

旧 SKILL.md は、資料を受け取るとすぐ checks.md で欠けを探し、見立てを立てないまま拾ったものを並べていた。手順 3「資料を読みながら checks の観点ごとの気づきを書き出す」が入口にあり、責任の導出と二択の段が無かった。項目は消していない。置く場所を変えた。

## 設計要件（10/27）から段に置いたもの

- 段1：依頼の二形。求められたこと・届く先・判断の席。完成は申告。
- 段2：チャット／ファイルで立てる事実の一覧。書いてあればそこから取る、無ければ確かめる。一度に一つ、土台に関わる一点から、答えが返ってから次へ。立てるのは事実だけ。
- 段3：責任の一文（役割の責務／約束／工程で当然）。受け入れ条件の具体。経路の役割。見立て（立った事実から自分の知識で状況を先に決める。10/27 本人が異論なしとした「あるべき流れ」の段）。
- 段4：二択の段と言い切りの設計。土台の二択が先。「である／でない」。未決は「決められる／決められない」→「事実がある／ない」で一つ聞く。
- 段5：面を選ぶ。相手（役割、経験、困りごと）、状況（段階、時期、経路、席）、中身（段4 の答え）。段4 の答えは変えない。
- 段6：段4 で決まったものだけから組む。「果たしていない」で止めない。最終決定は席の人。
