## 2026/05/18 事業見込対策MTG（相手：プロデューサー）｜判断1：見込みの数字を鵜呑みにしない

入力：経営企画と前回作った事業見込み（Tableau）。直接貢献額、版元からの開発費入金の振替、25名削減で17ヶ月黒字化という試算。

最初に問うたこと（順）
1. 見ているデータが最新・正しい版か（作成日を確認。「どの版を見て直ったと言ったのか」）。
2. 大きな数字（直接貢献6.39億）は何に対する数字か、計画とどう連動しているか。
3. 振替の内訳。合計は合っているか → 自分でリリースごとの金額を1つずつ読み上げて検算（「俺はまだ計算してないんで、計算したかどうかを知りたい」）。
4. 入金がPL上どこに乗っているか → 中間資料（名細）ではなく、誰でも見られる正本（Tableau）で見えなければならない。
5. 利益確定の時期。「なぜ9月に利益を確定するのか。差額が確定するのは3月」。開発遅延リスクが織り込まれていない。
6. 下期の営業利益悪化の中身。費目ごとに変動の有無を自分で確認（仕入・償却・人件費・通信費は変動なし → BS振替が原因と特定）。
7. 削減試算の前提。「25人削ったら単価が上がる（82.7万→90万）。それを計算に入れていない」→ 削減効果は想定より小さい。
8. 28年3月期まで見られるか → 見られない。シミュレーションできる環境がないと次の計画が立てられない。

辿った影響
- 9月に利益を確定 → 会社が吸収し、後の遅延分を事業で使えない。トータルは収まっても事業的にマイナス。下期が危ない計画なので特に。
- 単価上昇を無視 → 黒字化ボーダーの誤り。追加対策の要否が議論されていない。
- 配布（共通費）次第で損益が割れる → 事業内だけ見ていればよいというルール自体が破綻。

比較と重み
- 「向こう側で計算して大丈夫と言われたが、細かく見たら違っていたことがよくある」→ 他人の数字は信頼しない。自分たちで検算できる数字を持つ。
- 見込みは保守的に。「見込みでプラスが出るはずとは上程していない。実態が入ってプラスだったという方が良い」。
- 事業リスクがあるものは後ろに回してもらうべき。「プロデューサーならそういう話をすべき」。

決定・要求
- 1400万の計上が帳簿上避けられないか確認。避けられるなら27年3月に回し、見込みはプラマイゼロに。
- 未来の数字を見られる環境、またはデータ提供を受けて自分たちでシミュレーションできる状態にする。
- 期限を自分で逆算：経営企画との調整は今週水曜まで（自分が翌週不在 → 「今日逃すと月末まで無理」）。その後、黒字化に必要な削減人数のボーダー → プロデューサー間合意 → 人事・契約側へ協力依頼 → 月末までに完了。「合意が27、28日になると間に合わない」。
- ボーダーの先の実行（契約切替、機材、権限）を8月末までに担保できるかの確認も同時に。
- 損益ルール変更のロビー活動を継続。

切り替え変数
- 帳簿上避けられない計上なら受け入れる（避けられるなら回す）。
- 自分の不在期間が期限を決める。

問わなかったこと
- 売上そのものの低迷（「増やせんしな」）。流入・売上の改善策は論点にしない。

比較と重み

- 最適化検討は来期頭（1月）に開始し、来期上期末（9月）までに計画を着地。実動（引き継ぎ・入れ替え）は来期下期。
- リードに、1月に議論を始められるよう仮で日程を置いておくよう依頼（「1月になると他のことで忘れている」）。
- 別会社への移管も可（ただしRubyとゲーム理解の両方を持つ先は高い）。

9. 自分の計画を開示：会社から「下期で一人で任せられる体制を」と言われているが「無理だと答えている」。会社の意図（自分を他事業へ）は「PM部を潰すのでNG」。選択肢は「君を叩き上げてスタジオ長に上げるか、外から採用して据えるか」。「知らない人がいきなり上に来るのは嫌でしょ。今回も似たようなもの。2回繰り返すのはダメ」→ 1年半でスタジオ長に。「スパルタと言われるが、ついてきた人はみんな出世している」「厳しすぎたら言ってほしい」「僕はいつでも自分の席を人に明け渡したい側」。
10. 機密の線引き：部長クラス以上しか知れない数値・昇格基準は伝えない。それ以外は全部伝えてよい。
11. 「Mなのに昇格させたいと上がってきたら？」→「おかしいぞと言わなくていい。『Mなのに昇格って難しくないか』でいい」。

比較と重み
- 制度の文言より意図。意図を自分の言葉で定義し直して下ろす。
- 評価はスタッフが「何を目指し何が足りないか」が分かる状態にすることが目的。
- 自分が言えば業務命令、相手が言えば牽引。経路を選ぶ。
- 自分の地位・席は守る対象ではない。守るのは後任が育つことと、チームの推進者が消えないこと。

林の言葉
「本当は見せちゃダメだが、知っておいてもらわないと意味がない」「言語化できないのであればそれは分かっていないと思った方がいい」（前回）「僕がやるとただの業務命令になる」「スパルタだって言われますけど、ちゃんとついてきた人はみんな出世してる」「僕はいつでも自分の席を人に開け渡したい側」「おかしいぞって言わなくていい。Mなのに昇格って難しくないかでいい」

問わなかったこと
- 個々人の評価点の妥当性（グループ長に委ねる）。
- 前任者の過去の説明の是非（「文句言ってもらっていい」と流す）。
